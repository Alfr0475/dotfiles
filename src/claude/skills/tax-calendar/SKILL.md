freee から今年の数字を取り直し、税額を計算して、納税カレンダーの Artifact を上書きする。
数字の正本は freee。このスキルは計算の手順と見せ方だけを持つ。

## このディレクトリのファイル

| ファイル | 役割 | git |
|---|---|---|
| `SKILL.md` | 手順（このファイル） | 管理する |
| `template.html` | ページの見た目。`/*__DATA__*/` の行に data.json が入る | 管理する |
| `build.sh` | `build.sh <data.json> <出力.html>` でページを組み立てる | 管理する |
| `profile.local` | **個人の値**：freee の事業所 ID・タグ、Artifact の URL、国保の料率、控除の前提、取引先の源泉徴収など | **管理しない**（`*.local` で除外） |

**IMPORTANT: dotfiles は public リポジトリ。金額・事業所 ID・取引先名・URL などの個人の値は
`profile.local` にだけ書き、`SKILL.md` や `template.html` には書かないこと。**

## 手順

1. **`profile.local` を読む。** 無ければ作り方をユーザーに聞く（下の「profile.local に書くこと」）。
2. **freee から取る**（読み取りだけ。freee に書き込む API は呼ばない）
   - 事業所：`profile.local` の company_id
   - 売上・経費：`GET /api/1/reports/trial_pl`（`fiscal_year` = 今年）
     - 売上高は**税込**（税込経理）。先の月の請求書を freee 請求書で登録済みなら、それも入っている
   - 口座残高・売掛金：`GET /api/1/reports/trial_bs`
   - 払った税金・社会保険料：`GET /api/1/deals`（`type=expense`、`account_item_id`=事業主貸、今年の範囲）
     - 100 件ずつしか返らないので `offset` で全部取る。結果が大きいときはファイルに落として `jq` で集計する
     - どの支払いが何かは**タグ**で見分ける（タグ名と ID は `profile.local`）。タグの無い支払いは集計に入れない
   - 源泉徴収：`GET /api/1/deals`（`type=income`）の明細のうち、事業主貸に振られた行の合計
3. **計算する**（式は下の「計算のルール」）。わからない値を勝手に埋めない。仮定を置いたらページの「確認すること」か根拠の欄に書く
4. **data.json を書く**：スクラッチパッドに書く（形は下の「data.json の形」）
5. **組み立てて公開する**
   - `~/.claude/skills/tax-calendar/build.sh <data.json> <スクラッチパッド>/tax-calendar.html`
   - `profile.local` の Artifact URL に上書き公開する（別の会話からは、先に `action: "read"` してから `url` を付けて publish）
   - URL が無いときだけ新しく公開し、その URL を `profile.local` に書き足す
6. **ユーザーに返す**：取っておく額、次の支払い 2〜3 件、前回から大きく変わった点、確認事項だけを短く

## 計算のルール

- **事業所得** = 売上（税込）− 経費の年末見込み − 青色申告特別控除
  - 経費の年末見込み = （経費合計 − 減価償却費）× 12 ÷ 経過月数 ＋ 減価償却費
  - 12 月に入ったら年換算をやめて実績を使う
- **所得税**：所得控除（社会保険料・小規模企業共済等掛金・生命保険料・基礎控除・寄附金）を引いた課税所得（千円未満切り捨て）に速算表を当て、1.021 倍。源泉徴収と予定納税を引いた額が確定申告で払う額（百円未満切り捨て）
  - 社会保険料控除は「今年払った額」（年度ではなく暦年）
  - 基礎控除は合計所得の段階で変わる。改正が多いので、年が変わったら確かめる
- **消費税**：課税売上（税抜、千円未満切り捨て）× 7.8%。特例・簡易・一般のどれで計算したかを必ず書く。地方消費税 = 国税 × 22/78
  - 前年の国税が 48 万円を超えていたら中間納付がある。払った分を引く
- **住民税**：課税所得 = 所得 − 所得控除（住民税の額。基礎控除 43 万円、生命保険料は住民税の上限）。10% − 調整控除 ＋ 均等割
- **国保**：（所得 − 43 万円）× 所得割の料率 ＋ 均等割など。料率と固定部分は `profile.local`。上限額で頭打ちになることに注意
- **個人事業税**：（青色申告特別控除前の所得 − 290 万円）× 5%。かかるかどうかは `profile.local`
- **取っておく額**：今年の稼ぎにかかる分 ＝ 所得税（確定申告分）＋ 消費税 ＋ 翌年度の住民税 ＋ 翌年度の国保。国民年金は所得に関係ない固定額なので入れない。個人事業税はかかる場合だけ別に書く

## profile.local に書くこと

- freee：company_id、事業主貸の account_item_id、使っているタグ（国保・年金・iDeCo・住民税・消費税・所得税・予定納税・還付金など）の名前と ID
- 公開先の Artifact URL
- 国保：自治体、所得割の料率（介護分を含むか）、固定部分、直近年度の確定額
- 控除の前提：生命保険料控除、ふるさと納税、iDeCo・小規模企業共済の月額
- 源泉徴収のある取引先と、その計算
- 消費税：2 割特例・簡易課税・一般のどれか、届出の状況
- 個人事業税がかかるかどうか
- 毎年見直す値（基礎控除の段階、国保の料率など）と、最後に確かめた日
